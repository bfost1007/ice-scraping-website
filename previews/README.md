# Single-file website reference

Download `blake-scrapes-preview.html`, open it in a browser, or attach it directly
to Claude. The page menu switches between 19 exported screens from this branch:
homepage, four signup steps, owner/employee login, owner Home/Crew/Schedule/
Customers/Money, employee Route/Stats/Requests, and representative details dialogs.

Fonts and example photo placeholders are embedded. The preview makes no network
requests and contains no real credentials or customer records. Native inputs are
editable, but screen content uses fixed example values. Navigation works; real
authentication, persistence, employee operations, uploads, and photo compression
remain in the Next.js/Supabase application. This is not a production replacement
for that application. Font licenses are included inside the HTML.
